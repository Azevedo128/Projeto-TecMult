# Resumo do Trabalho Feito
Neste Projeto criei um jogo do tipo Endless Runner. O objetivo deste jogo é colectar o maior número de moedas e chegar o mais longe possivel no percurso. O jogo contem 3 niveis "Easy", "Medium" e "Hard" onde a diferença entre cada nivel é unicamente a velocidade do personagem. Quando um utilizador entra no jogo vai se deparar com o menu principal onde pode escolher os niveis(Select Level), começar a jogar(Start Game)(se não mudar de nivel irá começar no nivel "Medium") e sair do jogo(Exit Game). Quando um jogador bate num obstáculo, perde o jogo e vai para o ecrã "Game Over" onde poderá ver o numero de moedas coletadas e e a distancia percorrida, tentar outra vez imediatamente ou voltar para o menu principal.
# Controlos 
Mover para a esquerda: Teclas "A" ou "<-"(Seta para a esquerda)

Mover para a direita: Teclas "D" ou "->"(Seta para a direita)
